# スポーツマッチングアプリ 企画サマリー

## 1. 課題(既存サービスの不満点)

- labola・スポーツやろうよ等はPC前提のUIで、屋外でやるスポーツと相性が悪い
- 募集が「団体か個人か」わからない
- 募集単位が日付順のみで、団体の中身(レベル感・実績)は問い合わせないとわからない
- 結果として、社会人スポーツの情報発信は実質Instagramに集約されてしまっている(発見しづらい)

## 2. コアコンセプト

**「登録=自分のLPが自動生成される」**

個人も団体も、登録すると自分専用のページ(LP)を持てる。Instagramのプロフィールリンクにそのまま貼れるので、乗り換えコストがほぼゼロ。

## 3. 対象種目

野球・サッカー・バスケ・バレー・陸上(主要スポーツに限定)

## 4. 双方向マッチング(最大の差別化)

既存サービスは「団体が募集→個人が応募」の一方通行。このアプリは双方向。

| | できること |
|---|---|
| 団体LP | 募集中のポジション・人数、出場大会・戦績、メンバー構成、直接応募ボタン |
| 個人LP | ポジション・プレースタイル・レベル感、活動可能エリア/曜日、希望する参加形態(単発/正式加入/助っ人)、経歴 |

- 団体→個人LPを検索してスカウトできる
- 個人→団体LPを見て直接応募できる
- 問い合わせ不要で、空き枠・戦績・レベル感がLP上で完結(透明性)

## 5. UX設計

### 入り口を分ける
- 「探す/参加したい」入り口:タイミー的なカレンダー・地図ビューが前面。今週末どこで何があるか一覧→カードから各LPへ
- 「募集したい/声かけたい」入り口:自分のLP管理画面が前面。空き枠作成、個人LP検索・スカウト、応募者管理

### モード切り替え
- 登録時に「メインは個人?団体?」で初期ホームを決定
- ホーム画面の隅(タブバー等)に常時モード切替スイッチを配置し、両方使う人にも対応

### 一覧性
- タイミー型の「日付・カレンダー軸で何がいつあるか一覧できる」構造は踏襲
- ただし既存サービスと違い、カードの中に団体/個人の属性・LPへの導線を持たせる

## 6. Instagram勢の取り込み導線

- 団体側がInstagramアカウントをそのまま紐付けて団体LP化できる(発信の二重運用をなくす)
- 募集ポストを作ったら自動でInstagramにもクロスポスト

## 7. グロース戦略(PayPay型)

**フェーズ1:無料で母数と習慣化**
- LP作成・マッチング・スカウト、基本機能は無料開放
- KPIは登録数より継続利用率
- コストは実質サーバー代のみ(還元コストがかからない分PayPayより身軽)

**フェーズ2:ネットワーク効果が効いてから課金導線**
- 検索結果の上位表示
- LPデザインカスタマイズ
- スカウトの効率化ツール(既読管理・一括送信等)
- 蓄積データ(戦績・出席実績)の信用スコア可視化オプション
- 地域スポンサー広告枠(スポーツ用品店・整骨院等)

※団体向け機能課金は、既存無料サービスとの機能差がない限り成立しない → 基本機能は無料が前提

## 8. 初期営業方針

- 完全無料と言い切らない。「基本機能は無料」「先行ユーザー特典として今は全機能開放中」という言い方で将来の有料化に含みを持たせる
- 自分がプレーしている界隈(社会人サッカー等)から着手し、信頼を稼ぎやすい場所から広げる
- Instagramで発信している地元チームに直接営業
  - 二重投稿の手間なく露出が増える点を訴求
  - 問い合わせ不要で団体の中身が見える状態になる点を訴求
- 初期ユーザーには要望を反映しながら「一緒に作ってる感」を出し、定着率を上げる

## 9. 未決定・要検討事項

- LPの詳細テンプレート項目の最終化
- 信用スコアの算出方法(出席率・評価・大会実績など)
- 種目ごとの情報項目の違い(球技とランニング等の個人競技で必要な項目が異なる)
- 営業リストの具体的な作り方
